## Tabla 7 — Tablas relacionales → MER → PK → FK → Forma normal

| Tabla Relacional   | Entidad MER        | PK                              | FK                                                                                                      | Forma Normal                                                                                                      |
|--------------------|--------------------|---------------------------------|---------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------|
| ROLES              | ROLES              | PKRol INT AUTO_INCREMENT        | —                                                                                                       | 3FN: NombreRol y Descripcion dependen únicamente de PKRol                                                         |
| USUARIOS           | USUARIOS           | PKUsuario INT AUTO_INCREMENT    | FKRol → ROLES(PKRol)                                                                                    | 3FN: Nombre, Apellido, Correo, Contraseña, FechaRegistro, Estado dependen de PKUsuario                            |
| EJERCICIOS         | EJERCICIOS         | PKEjercicio INT AUTO_INCREMENT  | FKDocente → USUARIOS(PKUsuario)                                                                         | 3FN: Titulo, Descripcion, FechaCreacion, Estado dependen de PKEjercicio                                           |
| VECTORES           | VECTORES           | PKVector INT AUTO_INCREMENT     | FKDimension → DIMENSION(PKDimension), FKUsuario → USUARIOS(PKUsuario)                                   | 3FN: NombreVector depende de PKVector; dimensión referenciada por FK                                              |
| DIMENSION          | DIMENSION          | PKDimension INT AUTO_INCREMENT  | FKVectores → VECTORES(PKVector)                                                                         | 3FN: Tamaño depende únicamente de PKDimension                                                                     |
| DETALLE_VECTOR     | DETALLE_VECTOR     | PKDetalle INT AUTO_INCREMENT    | FKVector → VECTORES(PKVector)                                                                           | 3FN: Indice y Valor dependen de PKDetalle; UNIQUE(FKVector, Indice) garantiza atomicidad                          |
| OPERACIONES_SUMA   | OPERACIONES_SUMA   | PKOperacion INT AUTO_INCREMENT  | FKEstudiante → USUARIOS, FKVectorA → VECTORES, FKVectorB → VECTORES, FKEjercicio → EJERCICIOS (nullable)| 3FN con desnormalización intencional documentada en campo Resultado (JSON)                                        |
| METRICAS_DESEMPENO | METRICAS_DESEMPENO | PKMetrica INT AUTO_INCREMENT    | FKOperacion → OPERACIONES_SUMA (UNIQUE), FKEstudiante → USUARIOS                                        | 3FN: Intentos, Aciertos, TiempoSegundos, FechaRegistro dependen de PKMetrica                                      |
