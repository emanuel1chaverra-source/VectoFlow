# Alcance 

**3.1 Alcance Actual (Solo Suma de Vectores)**

Acceso a la plataforma: El sistema permitirá el registro e ingreso de usuarios (estudiante, docente y administrador) en cualquier momento que lo deseen, sin restricción de horarios ni secciones programadas.

El sistema incluirá las siguientes funcionalidades enfocadas exclusivamente en la operación de suma de vectores:

    •	Crear dos o más vectores unidimensionales con longitud y valores definidos por el usuario.
    •	Validar que todos los vectores tengan la misma dimensión antes de ejecutar la suma.
    •	Ejecutar la operación de suma elemento a elemento: C[i] = A[i] + B[i] + ... + N[i].
    •	Mostrar el proceso de suma paso a paso para comprensión didáctica (índice por índice, vector por vector).
    •	Guardar los vectores ingresados, la operación realizada y el vector resultado en la base de datos.
    •	Llevar un historial de sumas realizadas por cada usuario.

**3.2 Qué NO Incluye**

    •	Otras operaciones sobre vectores (resta, máximo, mínimo, promedio, ordenamiento, búsqueda).
    •	Operaciones intermedias (invertir vector, comparar vectores, copiar vectores).
    •	Aplicaciones algorítmicas (conteo de frecuencias, cálculo de moda/mediana/varianza, rotaciones).
    •	Gestión de horarios o secciones académicas.
    •	Animaciones de algoritmos de ordenamiento.

**3.3 Restricciones del Alcance**

    •	El sistema únicamente trabajará con vectores unidimensionales.
    •	Se limitará exclusivamente a la operación de suma entre dos o más vectores del mismo tamaño.
    •	Diseñada para estudiantes y docentes de ingeniería de sistemas de universidades públicas en Medellín.
    •	El desarrollo priorizará una versión funcional mínima (MVP) centrada en la suma de vectores.
