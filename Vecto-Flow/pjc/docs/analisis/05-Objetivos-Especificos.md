# Objetivos especificos

1.	Diseñar e implementar un módulo de creación y manipulación de vectores unidimensionales que permita al estudiante definir la longitud y valores de cada vector de forma interactiva.

2.	Desarrollar un motor de suma de vectores elemento a elemento (C[i] = A[i] + B[i]) con validación de dimensiones, que ejecute y almacene cada operación en la base de datos.

3.	Implementar un sistema de visualización paso a paso que muestre al estudiante, iteración por iteración, cómo se realiza la suma de vectores posición por posición.

4.	Construir un módulo de historial de operaciones que registre todas las sumas realizadas por cada usuario con fecha, hora, vectores operandos y vector resultado.

5.	Desarrollar un panel para docentes que permita crear ejercicios de suma de vectores, asignarlos a estudiantes y monitorear su progreso y desempeño.

6.	Implementar un módulo de administración de usuarios con roles diferenciados (Estudiante, Docente, Administrador) y gestión de acceso seguro.

7.	Diseñar una interfaz web responsiva y accesible desde escritorio, garantizando una experiencia de usuario clara y didáctica.
